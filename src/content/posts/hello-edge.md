这个博客的上一版跑在一台 VPS 上。它很好，直到某天证书过期、系统更新，或者我单纯忘了续费。

所以这次换了个思路：**把整个站点交给边缘网络**。没有常驻进程需要守护，没有操作系统需要打补丁，构建产物直接分发到 Cloudflare 的节点上。

## 技术栈

整套东西比想象中轻：

- **Vite** 负责开发和构建
- **React 19** 负责界面
- **Hono** 负责 API 路由
- **Cloudflare Workers** 负责运行和分发

前端构建成静态资源，API 跑在 Worker 里。两者共享同一个部署单元，改一行代码，`npm run deploy` 之后全世界同时生效。

## 文章是怎么来的

文章是仓库里的 Markdown 文件，构建时被 Worker 读取、解析、渲染：

```ts
const files = import.meta.glob("../content/posts/*.md", {
  query: "?raw",
  import: "default",
  eager: true,
});
```

没有数据库，也没有后台。想写东西的时候，新建一个 `.md` 文件，提交，部署。简单到不会因为"工具太复杂"而放弃写作。

## 代价是什么

边缘计算不是银弹。你需要接受：

1. 冷启动和运行时限制；
2. 调试体验不如本地进程；
3. 强依赖平台，迁移有成本。

但对我这种流量不大、更新不频繁的个人站点来说，这些代价远小于维护一台服务器的精力。

> 最好的基础设施，是让你忘记它存在的那一种。
